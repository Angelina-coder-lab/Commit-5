# Расчёт заработной платы (базовый уровень)

Модель предметной области и консольное приложение для расчёта зарплаты сотрудника за период.

## Модель

| Класс / тип | Описание |
|-------------|----------|
| `Employee` | Сотрудник (equals/hashCode по табельному номеру) |
| `PayrollPeriod` / `DateInterval` | Расчётный период и интервал дат |
| `RateSchedule` | Ставки и лимиты на интервалах дат (копейки / базисные пункты) |
| `PayrollElement` | Общий интерфейс элемента расчёта (OCP) |
| `Accrual` (sealed) | Начисления: оклад, премия, ночные, отпускные, больничный |
| `Deduction` (sealed) | Удержания: НДФЛ, аванс, исполнительный лист |
| `ElementKind` | Enum с полями и телом констант |
| `PayrollContext` | Контекст одного прохода расчёта |
| `Payslip` / `PayslipLine` | Расчётный листок с расшифровкой |
| `PayrollService` | Порядок: начисления → налог → удержания + лимит доли |
| `PayrollException` / `DeductionLimitException` | Свои исключения |

### Обязательные элементы
- **Интерфейс + иерархии + полиморфизм**: `PayrollElement`, sealed `Accrual` / `Deduction`, `calculate(ctx)`.
- **Перечисление**: `ElementKind` с полями и `sign()`.
- **Свои исключения**: `PayrollException`, `DeductionLimitException` с данными.
- **equals/hashCode**: у `Employee` (у record — автоматически).

### Операции базового уровня
1. Расчёт периода: начисления → налог от базы → удержания.
2. Проверка ограничения доли удержаний (по умолчанию 50%).
3. Расчётный листок с расшифровкой каждой строки.
4. Добавление нового вида начисления **без правки** уже написанных классов (через `PayrollElement`).

### Деньги
Все суммы — **целые копейки** (`long`). Проценты — в базисных пунктах (1300 = 13.00%).

## Сборка и запуск

```bash
mvn clean package
mvn test
java -Dfile.encoding=UTF-8 -jar target/payroll-1.0-SNAPSHOT.jar
mvn javadoc:javadoc
```

## Акцент
Принцип открытости-закрытости, enum с телом, арифметика по датам и в копейках.
